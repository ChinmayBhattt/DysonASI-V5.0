# DysonASI V5.0 🚀

**DysonASI** is an advanced AI virtual assistant designed to simulate intelligent human-like conversations. Built using the Gemini API, it combines rule-based predefined responses with generative AI, enabling both contextual and personalized interactions. This version focuses on enhancing user experience, chat memory, MongoDB integration, and a dynamic UI/UX.

## 🔍 Features

- ✅ Predefined intelligent responses for common queries  
- 🤖 Integration with **Google Gemini API** for AI-generated replies  
- 📂 Document upload support with contextual AI responses  
- 💾 MongoDB integration for persistent chat storage  
- 🧠 Automatic cluster creation for new chats  
- 📑 Sidebar view for accessing old conversations  
- 🧠 Smart NLP-based matching for similar questions  
- 🧱 Built using **Node.js**, **Express**, **JavaScript**, **MongoDB**
